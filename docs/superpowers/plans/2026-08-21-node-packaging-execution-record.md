## 1. Outcome

Plan 6 shipped both commands:

- `nodeflow:make-node-package` scaffolds an ordinary Composer/Laravel package with optional JavaScript entry files.
- `nodeflow:extract-node` proves a node is safe to move, performs journaled M1–M9 changes, installs it with Composer, and verifies exact type/class discovery in a fresh Laravel process.

The demo's `SendMessage` node was extracted into
`Atram\NodeflowDemoNodes\Nodes\SendMessage`. Five published flow versions containing fifteen
`demo.send` occurrences all resolved to that exact class after extraction.

The final design is materially stricter than the original plan code blocks: path containment is
portable and symlink-aware; PHP source analysis is token-based; Composer/Laravel mutable state is
disk-snapshotted with bytes, modes, directories, and symlink identity; recovery storage is retained
when restoration itself fails; and fresh-host discovery is the acceptance oracle.

---

## 2. Corrections execution forced

The most important corrections were discovered by executed counterexamples:

- `NodeTypeLiteral` had to scope constant and method lookup to the named class body and support legal braced namespaces.
- Provider removal had to parse array elements structurally with PHP tokens, absorb delimiter commas safely, and verify output with `php -l`.
- Reference detection became universal for resolved PHP names, with bounded Blade/heredoc/nowdoc scanning and shared G5/M6a roots and rewrite spans.
- Scaffold and extraction paths had to resolve canonically across Unix, Windows drive/UNC forms, symlink chains, cycles, and dangling targets.
- Composer installation required stable path-package aliases, isolated ambient configuration, whole effective vendor/bin/generated-state snapshots, and restore-only autoload regeneration.
- Laravel package/services cache paths had to come from the effective host Application, be contained and journaled, then be frozen into the fresh-process oracle.
- Whole-branch review caught two exit-0 semantic breaks: repeat extraction erased earlier package registrations, and unused-import cleanup erased unrelated comma/group members.
- The same review caught four important boundary/compatibility issues: late nested-symlink refusal after earlier scaffold writes, overlapping roots misreported as cycles, Composer brace globs rejected, and uppercase PHP-family files skipped.

The final fixes preserve existing matching-package files, add only missing Composer discovery structure,
preflight every output before writing, retain multi-member imports conservatively, separate active
cycles from completed roots, support bounded `GLOB_BRACE`, and scan extensions case-insensitively.

## 5. Known costs and residual limits

- Forward Composer uses `--no-plugins` as well as `--no-scripts`; plugin-dependent hosts fail loudly and roll back.
- Isolated `COMPOSER_HOME` and cache prevent ambient redirects but ignore global repositories, credentials, and cache unless credentials are supplied through process-safe configuration such as `COMPOSER_AUTH`.
- Whole-vendor rollback is intentionally proportional to the effective vendor tree in disk space and I/O.
- Package discovery invalidation can rebuild both Laravel package and services manifests.
- Failed restoration can intentionally retain private 0700 recovery roots; the command names them instead of deleting the only recovery bytes.
- The source scanner cannot prove dynamic/database-built class names, short Blade names, or references in unsupported file extensions.
- Multi-member imports may retain one harmless unused member rather than risk changing an unrelated import's meaning.
- Matching packages keep their custom files; missing Composer discovery/autoload structure is added, but conflicting existing structure is not silently overwritten and may make M8/M9 refuse.
- Composer brace expansion is capped at 256 candidates; more complex patterns refuse rather than consume unbounded memory.
- The demo's initial Composer topology required a temporary repository alignment because Composer refuses installing a nested worktree destination from its enclosing main checkout source. Tracked configuration was restored and normalized before commit.
